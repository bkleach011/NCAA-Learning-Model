# March Madness Bracket Predictor

A Python program that predicts NCAA March Madness game outcomes using team stats scraped from the web.

## How It Works
1. Scrapes team stats from NCAA and SportsReference using BeautifulSoup
2. Cleans and organizes the data using into lists ordered by team
3. Uses a learning model trained on previous tournaments to predict the outcomes of tournament games
4. Outputs a full bracket with win probabilities
